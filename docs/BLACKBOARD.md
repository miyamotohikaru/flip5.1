# 黒板（ガリレオ演出）— 設計と契約

## なぜ作るか
「数式だけで作った」と言われても、**最終形の式は端的すぎて凄さが伝わらない**。伝わるのは次の3つ。

1. **思考量** — 黒板いっぱいの導出。失敗して消した跡。何度も書き直した形跡
2. **因果** — このスライダーを動かすと、この項の数字が変わり、目の前の山（音）がこう変わる
3. **圧縮** — これ全部、たったひとつの種（シード）から出ている

黒板はこの3つを見せるための装置。アートと技術ショーケースの中間、そして「数式が世界を作る過程の追体験」を狙う。

## 絶対のルール（この作品の芯を壊さない）
- **手書きフォントのファイルを置かない。** 文字も数式で描く。1本線のベクトル字形（コードで持つ）＋ 決定的ハッシュのゆらぎ＋筆圧＋チョークの粉。
  「手書き風のフォントを読み込む」のは、この作品では**素材を使うのと同じ**。
- 見せる式は**実際に使っている式**だけ。`src/engine/**` の該当箇所を出典として持ち、嘘を書かない。
- 決定的（`Math.random` を使わない）。同じ URL・同じシードなら誰が開いても同じ黒板。

## 実装方式（決定事項）
**SVG + 手続き的な線文字 + feTurbulence のチョーク + stroke-dashoffset の書き取り。**
- **SVG** … 項ごとに `<g data-term="...">` を持てるので、ハイライト・数値の差し替え・クリックがそのまま書ける
- **線文字（stroke font）** … `src/blackboard/strokefont.ts` に字形をポリラインで持つ。1文字＝数本のストローク。
  ゆらぎは `hash2` 由来（同じ文字でも位置ごとに違い、再描画では同じ）。線幅は筆圧カーブで変える
- **チョーク** … SVG フィルタ `feTurbulence` + `feDisplacementMap`（ノイズはブラウザ内蔵の手続き的生成＝素材ゼロのまま）で
  線を毛羽立たせ、`feGaussianBlur` の薄い層で粉を散らす。黒板の地は緑黒（#16211c 系）＋消し跡のむら
- **書き取り** … 各ストロークを `stroke-dasharray` / `stroke-dashoffset` で 0 → 全長へ。ペン速度は文字の大きさで変える
- **消し跡** … 失敗した式は打ち消し線＋半透明の白い帯（黒板消しの跡）を残す。**消して終わりにしない**（試行錯誤の痕跡が主役）
- WebGL は使わない。世界（three.js）の上に載る React の層。`?nohud=1` で消えること

## データ契約 `src/data/formulas.ts`
式は**文字列ではなく木**にする。項を指して光らせ、数値を差し込むため。

```ts
export type Node =
  | { t: "sym"; s: string }                     // 記号・変数（x, z, π, Σ …）
  | { t: "num"; v: number; d?: number }          // 定数（d = 小数桁）
  | { t: "op"; s: "+" | "−" | "·" | "/" | "=" | "<" | "≈" }
  | { t: "fn"; name: string; args: Node[][] }    // sin(…), fbm(…), exp(…)
  | { t: "frac"; num: Node[]; den: Node[] }
  | { t: "sup"; base: Node[]; sup: Node[] }      // 上付き
  | { t: "sub"; base: Node[]; sub: Node[] }      // 下付き
  | { t: "sum"; from: Node[]; to: Node[]; body: Node[] }
  | { t: "int"; from: Node[]; to: Node[]; body: Node[]; d: string }
  | { t: "term"; id: string; body: Node[] }      // 光らせたい単位（スライダーと対応）
  | { t: "live"; id: string; d?: number }        // 実行中の値を差し込む場所
  | { t: "brk" };                                // 改行

export type Formula = {
  id: string;
  /** 黒板の見出し（日本語・短く） */
  title: string;
  /** どの分野か */
  area: "terrain" | "sky" | "water" | "vegetation" | "weather" | "audio" | "core";
  /** 出典（実際のコード。file:line。嘘を書かない） */
  src: string;
  /** 式そのもの */
  body: Node[];
  /** 導出の段階（黒板で順に書かれる）。failed:true は打ち消し線＋消し跡 */
  steps?: { note: string; body: Node[]; failed?: boolean }[];
  /** 実行中の値。world から毎フレーム引ける（間引いて 100ms に1回でよい） */
  live?: (w: World) => Record<string, number>;
  /** スライダーで動かせるパラメータ */
  params?: {
    id: string;      // term の id と対応（動かすとその項が光る）
    label: string;   // 日本語
    min: number; max: number; step: number;
    get: (w: World) => number;
    set: (w: World, v: number) => void;
    /** 変えたら世界を焼き直す必要があるか（地形など） */
    rebake?: boolean;
  }[];
};
```

## 見せる場所（4つ）
1. **入口＝黒板**（`/` の第一画面）。世界が薄く透けた黒板に、式が書かれていく。
   地形 → 空 → 水 → 木 → 音 の順。**失敗した式（打ち消し線）を必ず混ぜる**。
   書き終わると「入る」。読み込みの待ち時間をそのまま演出にする（今の読み込みログを置き換え）
2. **世界の中の隅**（キー `G` で出し入れ、既定は出す→8秒で薄くなる）。
   いま見ているもの（照準の先）を生成している式を1本だけ、実行中の数値つきで。うるさくしない
3. **実験室モード**（HUD の「いじる」）。スライダーで実際のパラメータを動かす。
   動かした瞬間に**対応する項が光り → 数値が変わり → 風景と音が変わる**。「戻す」で既定値へ
4. **締め**（実験室の最後・About の末尾）。
   「ここまで全部、この数ひとつから」→ シード値を表示 → 変えると谷ごと別物になる

## 導出に混ぜる「実際の失敗」（本当にあったもの。嘘を作らない）
- 地形: 共通のノイズを重ねただけ → **山が団子になった** → ドメインワープ＋東西走向の尾根＋侵食で書き直し
- 草: 葉幅 0.034m・藁色 → 批評で「2005年のゲーム」→ 0.010m・地形の緑に合わせる
- 空: 夕焼けが白い（Mie 3.2e-3）→ 8e-3 に上げて橙が出た
- 水: `pow(a·b, 2.5)` で a·b が負 → **NaN** → ポスト処理が黒い筋として空へ引き伸ばした
- 共通: 空の `#define PI` と水の `const float PI` が衝突してシェーダが無言で死んだ
出典は `docs/critique/round1.md` と各担当の報告。

## 性能
黒板は SVG。書き取り中でも 60fps を保つ（ストロークは最大 2000 本まで、書き終わったものは1枚に畳む）。
世界の描画（12ms 予算）を邪魔しない。実験室のスライダーは、地形の焼き直しが要るものだけ
ドラッグ中は 256² の粗い焼き直し、離したら本焼き（Worker）。
