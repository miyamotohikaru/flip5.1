# 批評の手順（辛口審査）

この作品の完成条件は「AAA（RDR2 / Horizon / 最近の CoD の屋外シーン）のスクリーンショットと並べて、
どちらが本物のゲームか当てられないこと」。批評担当は制作担当とは別の目で、毎ラウンド次を行う。

## 撮る
```
node tools/shoot.mjs rN --all            # 12定点（shots/rN_<定点>.png）
node tools/shoot.mjs rN_m --shot golden --mobile
node tools/shoot.mjs rN_m --shot forest --mobile
python3 tools/sheet.py rN                # 一覧表 shots/rN_sheet.png
python3 tools/sheet.py --pair r(N-1) rN  # 前ラウンドとの並び
```

## 採点（定点ごと・10点満点）
| 観点 | 落第の例 |
|---|---|
| 光と大気 | 空がグラデーションの板／遠景が灰色一色／影が浮いている／夜が青いだけ |
| 材質 | ベタ塗り／タイル感／のっぺり／濡れ・雪・岩の質感が無い |
| 形 | 山が団子／木が円錐／草が板／岸線が硬い一本線 |
| 密度と自然さ | 一様な配置／群落が無い／人工的な繰り返し |
| 破綻 | 割れ目／ポップ／ジャギ／Zファイト／影のアクネ／水面のずれ |
| 仕上げ | ブルームで眠い／エフェクト感／色が安っぽい |
| 裏返し | 数式ビューが「ワイヤーフレーム表示」でしかない／正体が伝わらない／縁の波が美しくない |

各定点に「点数」「最も目立つ欠点（1つ）」「直し方の指示（担当モジュール名つき）」を書く。
合格は **全定点 9 点以上**、かつ携帯（mid）でも 7 点以上。

## ブラインド比較（最終ラウンド）
批評担当は、AAA の実写真的なスクリーンショットの記憶と本作の画を「どちらが本物のゲームのスクリーンショットか」
の問いで比べ、**必ずどちらかを選ぶ**。本作が選ばれない定点は不合格。理由を一行で。

## 記録
結果は `src/data/critique.json` に追記する（サイトの「検証ログ」ページが読む）:
```json
{ "round": 1, "date": "2026-09-02", "scores": { "golden": 6, ... }, "verdict": "不合格", "notes": ["golden: 遠景の霞が灰色。sky", ...] }
```

## 定点を変えたときの記録（透明性のため必ず残す）

定点（`src/engine/core/params.ts` の `SHOTS`）は批評の物差しそのものなので、**変えたら理由を必ずここに書く**。
点を取りに行くための変更は禁止。「その構図が写真として成立していない」ときだけ動かす。

- **2026-09-03 `noon` / `cloudy` を移動。** 旧位置は太陽がカメラの真後ろ 23°にあり、
  影が物陰に隠れて「昼なのに落ち影が 1 本も無い」画になっていた（影担当が実測で確認。
  カスケードの配り方・`shadowMaxFar`・雲の影のどれを変えても 1px も変わらないことを検証済み）。
  写真として成立しない構図なので、木の近く・太陽が横から当たる向きへ移した。
  **影の仕組みは変えていない。** 併せて木が影を落とす距離（120m）を伸ばす作業を植生担当に依頼した。
