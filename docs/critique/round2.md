## 新たに見つけた破綻

R1 から持ち越しの 3 点を先に:

1. **湖底の白／マゼンタの輝点 → 消えた。** 12 定点を自動検出（局所中央値 +0.35 かつ輝度 >0.85 の孤立画素、およびマゼンタ判定）にかけて、
   `sunset_water` `rain` `golden` `noon` `dawn` `cloudy` `forest` `ridge` すべて 0 件。
   残った検出は night の蛍・storm の閃光と水滴・flip の火花で、いずれも意図した光。**この項目は完了。**
2. **湖面下に草 → 残っている。** `r2b_noon` の x=670–1020 / y=640–700 に、砂帯を越えた青緑の水中に草の葉がはっきり立っている。
   同じ場所に白い斑（泡かゴミに見える）も浮く。
3. **雨の湖面の白い砂嵐 → 残っている。** `r2b_rain` の y≈390–450 と `r2bx_rain_water` の y≈460–560。
   6 倍に拡大すると 2px 周期の市松ノイズで、スパークルではなく「スペキュラのエイリアシング」。映り込みが完全に消える。

R2 で新たに見つけたもの:

4. **インポスターの矩形ぼけ（LOD の破綻）** — `r2b_cloudy` x=1280–1600 / y=440–540、`r2x_treeline`、`r2bm_golden`。
   木が 50×90px のぼやけた矩形の塊になる。mip の落としすぎかアトラスの詰め方の問題。
5. **葉カードのアルファ・ディザ（網戸模様）** — `r2b_ridge`（x≈600–640 / y≈180–330、x≈920 / y≈400–450）、`r2bm_forest`（x≈425–560 / y≈200–300）。
   携帯では 1 本の木に 3〜4 か所出て、遠目にも「メッシュのカーテン」に見える。
6. **反射バッファのブロック** — `r2b_golden` x=700–1200 / y=505–665。`quality.ts` の `reflectionScale` が high でも 0.5 で、
   映り込んだ山が 4〜5px のブロックになる。0.75 に上げるか、双方向フィルタで拡大する。
7. **地形スプラットの矩形タイル継ぎ目** — `r2b_ridge` x=1050–1250 / y=400–520、`r2bx_shadow` x=1000–1250 / y=180–330。
8. **湖面の横縞バンディング** — `r2b_night` x=0–1450 / y=595–650。等間隔の明暗の帯。
9. **岸の白い玉** — `r2b_rain` (840,570) (970,565) (1050,590) (1250,625) (1370,650)。草の中に白い丸が浮き、キノコかゴミに見える。
10. **空の埃の白い点** — `r2b_storm` (980,342)。R1 で指摘した「昼の空に見える埃粒子」が嵐でも出る。
11. **空の淡い斜めの網目（ディザ）** — `r2bx_sunface174` の青空。3 倍に拡大するとクロスハッチが見える。バンディング対策のディザが強すぎる。
12. **遠景の岸に橙の水平な線** — `r2b_sunset_water` x=1330–1500 / y≈480。1px の明るい線が水平に走る。
13. **雷が毎回同じ位置・同じ形** — 待機 4.0s と 7.7s の 2 枚（`r2b_storm` / `r2x_storm2`）で稲妻の折れ線が完全に一致。時刻から決まる種のはず。
14. **裏返しの境界が直線のポリゴンの縁** — `r2x_flipedge` (0,555)–(250,620) と、白い床の縁 (240,600)–(1600,660)。
15. **携帯の入口で数式が 3 行重なる** — `r2u_landing_m`。1 行目と 3 行目が同じ文字列で重畳する瞬間がある（差し替えのクロスフェードが見えている）。

## 次に直すべき上位 10（効果の大きい順）

1. **post（露出とトーン）** — 5 定点（golden / dawn / sunset_water / forest / flip_half）の下 1/3 が黒く潰れて情報が無い。
   R1 の「白飛び」を直しすぎて逆に振れた。目標値: 日なたの草 = 表示輝度 0.32〜0.45、影の中 = 0.05〜0.09、夜の月明かり = 0.02〜0.04。
   `post/exposure.ts` の基準を `0.24/keyL` → `0.30/keyL` に戻し、代わりに AgX の肩を寝かせて白側の脱色を防ぐ。影に空の環境光を必ず残す（下限 0.03）。
2. **core/lighting（影）** — noon / cloudy / treeline に落ち影が 1 本も無い。画面の 6 割を占める中景が「均一に明るい模型」のまま。
   近カスケードを昼にも有効化し、200m までの木の落ち影を出す。合わせて `post/ao.ts` の半径 0.6m・強度 0.6 で株と幹の接地を暗くする。
3. **vegetation（草の密度）** — 色と幅は直ったが本数を落としすぎ。
   目線 1.6m で 10m 先まで地面のノイズ塗りが見えないところまで戻す（今の 1.8 倍）。
   高さは `0.32·(0.4+1.0r)` のまま、密度の fbm（λ12m）の谷を 30–40% → 15–20% に浅く。
4. **vegetation/impostor（矩形ぼけ）** — 一目で「ゲームですらない」と分かる破綻。
   `minFilter=LinearFilter`（mip 無し）か anisotropy 8、切り替え距離をメッシュ側の 1.3 倍に伸ばして重ねる。
5. **water（雨の湖面の市松ノイズ）** — 雨定点の 4 割を占める湖が壊れて見える。
   `varAA` 上限 0.05 → 0.25、`varCap` のフットプリント閾値を 1/2.5 に、`water_rain` を 10m 以遠で切る。粗さの下限を距離で上げる。
6. **terrain（林床と斜面の土）** — 針葉樹の下が砂丘、尾根がぼけた水彩。
   `fFloor` を木の配置と同じソースから作る（今 forest 定点で効いていない）。斜面の土は λ 6m / 1.5m の 2 段に。スプラットの UV を world.xz に統一してタイル継ぎ目を消す。
7. **sky（黄昏の色）** — 17.4 時（golden 定点そのもの）で太陽側の空が白い。
   Mie 8e-3 → 1.4e-2 /km、g 0.82 → 0.86、`hazeKm` の増幅を sunDir.y<0.25 で ×2.5。
   検証は `?t=17.4&look=106,10` で R>G>B の橙になること（今は R≈G≈B）。
8. **vegetation/shaders（葉のディザ）** — 携帯で最も安く見える要素。alphaToCoverage（MSAA 4x）か alphaTest 0.4 + 葉の縁 1px のソフト化に。
9. **terrain + vegetation（岸）** — 砂帯が「プールの縁」のまま、かつ水面下に草。
   砂帯は幅 1〜3m・縁ノイズ λ6m。草は `heightAt(x,z) > uLakeLevel + 0.15` でのみ生やす（今は湖岸の内側まで出ている）。
10. **裏返し（core/flip + vegetation + terrain + ui）** — 波の縁の帯（幅 8–15m）＋先行リップル 3 本＋火花、木を骨組み（幹＋輪生 5 段の線）、
    等高線の主線／副線 4:1、下の空白に「草」のラベル。ここは R1 で唯一「数式が画の中に無い」が直った項目なので、残りを詰めれば flip_full は 8 まで届く。

## 批評側の注記

- 撮影中に別の担当（実験室）の統合が入り、`forest` と `ridge` の地面だけが変わった。採点は後の版（`r2b_*`）で統一してある。
  前の版（`r2_*`）も残してあるので、地面の変更の是非は 2 枚を並べて確かめられる。
- **今回いちばん正確に評価したいこと**: 木の輪郭・山の形・夜・雨の遠景・輝点の始末は、R1 の指示を超えて良くなっている。
  `r2x_sunface179`（17.9 時）と `r2x_water_low`（真昼の水面すれすれ）の 2 枚は、単独で見れば AAA と区別がつかない水準に達している。
  それでも 12 定点すべてが「されない」なのは、**その水準が画面の一部にしか行き渡っていない**からで、
  上位 1・2（露出と影）を直せば、既にある作り込みが表に出て 2 点前後は自動的に上がる。
- 合格条件（全定点 9・携帯 7・ブラインド全「される」）までの距離は R1 より確実に縮んだが、まだ遠い。
  次ラウンドは上位 1・2・3 だけを直した画で再撮影し、差分を見るのが早い。
