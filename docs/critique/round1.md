## 上位 10（効果の大きい順）

1. **vegetation（草）** — 9/12 定点の前景。葉幅 0.034/0.045/0.06 → 0.010/0.014/0.020 m、高さ 0.42·(0.55+0.8r) → 0.32·(0.4+1.0r) で株ごとに相関、`GRASS_COLORS` を tip (0.11,0.21,0.05) / tip2 (0.14,0.20,0.06) / dry (0.32,0.26,0.11) / root (0.04,0.08,0.02) に（地形の草色 (0.050,0.115,0.025) の 2 倍以内）、`col *= 0.82+0.36·rnd` → 0.9+0.2·rnd、乾いた株 ≤ 20%。密度に λ≈12 m の fbm を掛けて 30–40% を短い/薄い斑に。環 B/C は 1 枚板をやめ 3 枚の株。第 2 層として広葉の雑草の円盤 5%・花穂 1%。地形側は葉の間に見える土・枯れ草のリター (0.20,0.16,0.08) を 30%。
2. **vegetation（木）** — 輪生を消す: `perWhorl` 6–7 → 12–16、輪生の高さジッター ±0.02 → ±0.08H、枝長 ±20% → ±45%、垂れ角 8+30(1−u)° → 15+35(1−u)°＋ばらつき ±10°。梢の交差カード 2 枚（電球に見える）→ 短い輪生 3 段の小さな円錐。針葉カードの充填率 70%、色 (0.03,0.06,0.02)〜(0.09,0.14,0.04)。幹 `veg_bark` light (0.34,0.27,0.21) → (0.20,0.16,0.12)。樹高 0.6–1.3×（森林限界に向けて低く）。配置: `forestDensity` に λ 40–80 m のクラスタノイズを掛け、空地 30%。インポスターは無光アルベドをベイクして表示側で照明。
3. **sky（黄昏・薄明の色）** — Mie 散乱 `mS` 3.2e-3 → 8e-3 /km、吸収 0.35e-3 → 1.0e-3、晴天の `hazeKm` 0.008 → 0.025（sunDir.y < 0.15 で ×1.8）、位相 g 0.76 → 0.82。太陽の光冠 `0.004·exp(−ang/0.012)` を低高度で `0.02·exp(−ang/0.05)` に。確認: `?t=17.4&look=106,10` で太陽側の空が (R>G>B) の橙になること。
4. **sky/post（夜）** — 露出上限 30 → 6（`target = clamp(0.8·(0.33/keyL)^0.65, 0.5, 6)`）。月明かりの地面は表示輝度 0.03–0.06。星密度 0.012+0.03·band → 0.004+0.012·band、輝度上限 0.25、天の川 0.0022 → 0.006。星の veil −0.19..−0.04 → −0.25..−0.10。蛍（weather）: `max(0.1, px·8)` → `max(0.012, px·2.5)`、520 → 150、地上 2 m 以内・湖上なし。月の映り込みの筋（water）。
5. **terrain（山と雪）** — 遠景法線を 2048 ハイトマップの 3×3 Sobel で（aux 1024 の面取りを消す）。雪: roughness 0.55 → 0.8、λ 2–5 m のサスツルギ法線ノイズ、45° 超の斜面から外す。岩: `strata` の振幅 mix(0.78,1.15) → mix(0.55,1.25)、斜度 0.5 超に 6–12 m 間隔の横縞と 0.6 倍の暗さ。core への要望: `heightAt`/`flip_height` に稜線の細部（リッジノイズ 2 オクターブ、λ 90/45 m、振幅 12/6 m、斜度 > 0.3 で有効）を足す（統合担当）。
6. **weather（雨・嵐）** — 雨筋 alpha 0.8 → 0.3、長さ ×0.5、`1−smoothstep(6,12,dist)` で消す、高い層は 6 m 以内。しぶき: 白い V スプライトを廃止、1 px のリング＋暗点。レンズ水滴: 径 1/3・屈折・見上げ時か突風時のみ。閃光: 雷の位置から 1/(1+(d/500 m)²) で減衰、空の上限 3 倍、80 ms の影付き方向光。湖面の雨: 法線リング（4 mm、0.6 m/s、40/m²/s）。埃: HG(g=0.7)×6 m 以内。
7. **water** — 岸際の楔（`r1x_water_low` 左下）を直す。泡マスクは水際 0.3–1.2 m の帯だけ（`foamTex` 閾値 0.62 → 0.78、alpha ≤ 0.6）。映り込みの継ぎ目（fallback を 20 px でぼかす）。遠方の粗さ: 風 3 m/s で 300 m 先 σ 0.02 → 0.06（縦ぼけ）。低い太陽・月のギラつき: GGX α 0.05 → 0.12（sunDir.y < 0.2）。
8. **post（仕上げ）** — フレアの輪 halo 0.16 → 0.05・雲量でゲート、光冠の半径 ≤ 6°。`uFlareStrength` 0.6 → 0.25。ビネット 0.28 → 0.18。夜明けの `uSplit.x` 0.35+0.3·night → 0.2。黄昏の白飛び: 日なたの草が表示輝度 0.8 超なので露出の基準 `0.33/keyL` → 0.24/keyL（AgX の白側での脱色を避ける）。AO 半径 ≥ 0.6 m で幹・株の接地。輝点（白・マゼンタ）の原因特定。
9. **controls/ui** — 携帯 HUD 左上に未タッチのスティック円が出る（`Joystick.tsx`: `stick` が x=y=0・inactive でも描く）→ `active` まで非表示か既定位置（左下 96 px, 下 120 px）。入口の左下ヒント／クレジット（`Landing.tsx:68-73`）が方位バッジ N と重なる（desktop/mobile）→ padding-left 56 px。携帯の数式行が右にはみ出す → `overflow:hidden; text-overflow:ellipsis`。core: `params.ts` の「yaw 右回りが正」は実装（three.js の rotation.y＝左回りが正）と逆。注記を直すか符号を合わせる。
10. **裏返し（全モジュール）** — 縁を幅 8–15 m の帯＋先行リップル 2–3 本＋火花。草の線は 6 本に 1 本。木は骨組み（幹＋輪生の線）。等高線 10 m で主線/副線 4:1。粒子は 1 px 点＋軌跡。世界の中に数式ラベルを 3–4 か所（ui）。空の弧は 1 段刻み。

## 見つけた不具合（採点とは別）

- water: 黒い四角の斜めの筋（既知）。`r1x_water_low` 左下の楔状の継ぎ目（同根の可能性）。
- post/weather: 白・マゼンタの輝点（`r1x_rain_water` (1165,552)、`r1x_moon_water` (1390,447)、`r1_sunset_water` 下部）。
- weather: 昼の空に白い点（埃粒子が空を背景に見える）。
- post: 太陽を囲む巨大な輪が常時出る（`r1x_sun12`）。
- controls/ui: 携帯 HUD 左上のスティック円、入口ヒントと N バッジの重なり、携帯の数式行のはみ出し。
- core/post: `?dbg=nopost` が真っ暗で切り分けに使えない。
- core: `params.ts` の yaw の向きの注記が実装と逆。
