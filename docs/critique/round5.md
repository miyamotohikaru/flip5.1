一言で: **今ラウンドは「直した」と報告された 10 項目のうち、実際に画で確かめられたのは 3 つだけだった。**
林床の色（オレンジ砂 → 中性の褐色）、草の直線切れ（→ なめらかなフェード）、木の等間隔（畑の畝 → 不規則）は本物である。
だがそれと引き換えに、**`forest` と `ridge` と携帯の `forest` が R4 より悪くなった**。
そして**最重要と名指しした 2 つ — 150m のパゴダと、インポスターの水平な板（金床）— は、どちらも直っていない**。
`dbg=imponly` と `dbg=notrees` で切り分けたので、これは推測ではない。

いま負けている理由は R4 から入れ替わった。R4 は「地面と木の LOD」だった。R5 は:

1. **木そのもの。** 近景（5〜20m）の葉カードが**巨大な淡いミント色の台形**になり、原寸で「切った工作用紙」と読める。
   中距離（30〜150m）の木は**幹だけの棒に房を 3〜4 個刺した形**になり、樹頂から**幹が角材のように突き出て**いる。
   遠景（150m〜）は**将棋の駒／ボウリングのピンに帽子**の輪郭になった。パゴダは形を変えただけで消えていない。
2. **近景の地面が暗すぎる。** `cloudy_side` の手前の地面は表示線形 **0.0241**、空は **0.8761**。**空の 2.8%** である。
   同じ光の中で 60m 先の草地は 0.1795（空の 20%）。**同じ曇天の下で、手前の地面だけが 7.4 倍暗い。**
   境目は画面上ではっきり見える曲線で、焼け跡か油の染みに見える。`forest` の林床も同じ理由で 0.0130 まで落ち、
   黒潰れが 0.10% → **0.94%** に増えた。これは R4 に無かった**新しい破綻**である。

## 前ラウンドの誤りを 3 つ取り消す（R−B を使った判定）

`docs/CRITIC.md` の「色みの判定に R−B を使わない」を R4 の指摘に適用し直したところ、**R4 自身が 3 か所でこの誤りを犯していた**。
批評側の非を先に書く。

| R4 の指摘 | 実測（R−G / R/G） | 判定 |
|---|---|---|
| 6番「1km 先の林の隙間が錆色（マルーン）」 | R4 の時点で **R−G = −4.0 / R/G = 0.954**（緑優勢） | **誤り。錆色ではなかった。** R−B=+31 を見ていた |
| 7③「濡れた砂の赤紫が悪化（R−B +15.3→+17.5）」 | R4 の時点で **R−G = −3.0 / R/G = 0.980**、R5 は **−7.0 / 0.951** | **誤り。赤紫は最初から無い。** |
| 19番（同上） | 同上 | **誤り** |

したがって「林床の色を直した」という担当の報告のうち、**「錆色を消した」の部分は最初から存在しない問題を消したこと**になる。
ただし**林床そのものの R/G は本当に直っている**（下の答え合わせ 1 番）。両方きちんと書く。

いっぽう **嵐の空のマゼンタは本物**だった。R−G = **+21〜+27**、G が 3 チャネルの最小＝純マゼンタ。R5 でも変わっていない。

## 「言葉と版面」の変更（作者の指示 4 点）の確認

作業中に入った 4 点を撮り直して確認した。**4 つとも実施されており、いずれも改善である。**

1. **「裏返す」→「ふりっぷする」** — 入口本文（「ふりっぷすると、確かめられます。」）、HUD の主ボタン、
   操作ヒント（`F ふりっぷ`）、携帯のボタン（裏返し中は「もどす」）まで揃っている。**作品名と動作が重なって、
   一語で何が起きるか分かる**ようになった。「裏返す」より短く、押す前の心理的な重さも減っている。良い改名。
2. **入口のクレジット削除** — 左上の「こす.くま ／ ふりっぷ」と右下の「制作: こす.くま × Claude Fable 5.1」が消えた。
   黒板の板面が広く見え、右上の `MATHSCAPE` だけが残るので**額装として静かになった**。
   ただし**右下と左下が広く空いた**ぶん、黒板の右段が上半分に片寄っている構図の不均衡が目立つようになった（下の減点）。
3. **操作ヒント 40 秒** — 4 秒後に出て 45 秒後には消えている（実測）。**読む時間は足りるようになった。**
   ただし**明るい草の上で灰色の文字が読めない**（`r5_hud` 下端中央）。時間を伸ばしても読めなければ意味が薄いので、
   文字に 1px の暗い縁か、幅 900px・高さ 28px の α0.25 の暗帯を敷くこと。
4. **携帯の「いま計算していること」の重なり** — ジャイロのボタンとも操作ヒントとも重なっていない（`r5m_hint`）。解消を確認。

**注記**: `?shot=` は `nohud=1` なので 15 定点の採点には影響しない。世界の絵は変わっていない。
