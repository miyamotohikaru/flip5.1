## 批評側の自己訂正 —「岸のにじみは細い帯のジャギ」は私も担当も間違いだった

R4〜R6 の 3 ラウンド、私は「幅 1m の帯が 1.5km 先で 1 画素を切るからにじむ」と書き、
R6 では**犯人でない 4 行を名指しして担当に渡した**（担当が 1 行ずつ切って「どれも違う」と返してきた）。
今回は名指しの前に切り分けた。手順と結果を残す。

1. `?shot=noon&dbg=noveg` で残る → **地形**（R6 と同じ）。
2. `?tdbg=2`（AO）・`?tdbg=3`（法線）に**にじみは出ない** → 照明でも法線でもない。
3. `?tdbg=8`（地色だけ）・`?tdbg=9`（細部なし）には**出る** → アルベドの層。「細部」の層でもない。
4. **`?tdbg=12`（砂/土/ガレのマスク）に、彗星形がそのまま赤で出る**（`shots/r7t_12.png` の
   (1350,480)-(1600,640)）。**犯人は `sandM`（浜のマスク）そのもの。**
5. **`--dpr 3` で描いて 1600×900 に縮小しても、形はまったく変わらない**（std 11.10 → 9.77、
   3 倍で描けば標本化のジャギは 1/3 に落ちるはずなので、これは決定的）。**＝ジャギではない。**

**結論は「細さ」ではなく「幾何」だった。** 1.5km 先の対岸はほぼ平らで、視線とほぼ平行に見ている。
だから**幅 1〜3m の浜の帯が、画面では奥行き方向に 200 画素の細長い舌になる**。それが彗星の尾の正体である。
そして `glsl.ts:186` の

```
float shoreFar = 1.0 - 0.6 * smoothstep(90.0, 320.0, tDist);
```

は **320m 以遠でも浜を 40% の濃さで残す**。だから 1.5km でも消えない。
（`bn1` は 110m、`bn2` は 380m、`wetBand` は 180m で消しているのに、**`sandM` 本体だけ消していない**。）

**直し方は 1 行**: `1.0 - 1.0 * smoothstep(90.0, 600.0, tDist)`（600m で浜そのものを消す）。
幅 3m の浜は 600m で 1.5 画素なので、消しても「岸に浜がある」という情報は失われない。
併せて 184 行の `flip_vnoise(tXZ * 1.8 + 4.0)`（λ≈0.56m）にも `bn1` と同じ距離フェードを付けること。

**教訓（`docs/CRITIC.md` に足すべき）: 「細かすぎてジャギになっている」と思ったら、
`--dpr 3` で描いて縮小してみる。形が変わらなければジャギではない。** 3 ラウンド無駄にした。
